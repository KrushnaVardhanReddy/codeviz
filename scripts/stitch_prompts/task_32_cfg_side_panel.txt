Create a sliding side panel component for the Web UI.
When a user clicks on a function node in the React Flow graph, this panel should slide in from the right.
It will display the Control Flow Graph (CFG) for that specific function.
Requirements:
1. Glassmorphism effect on the background.
2. A close button ('X') in the top right.
3. A sub-diagram area specifically for displaying the function's internal execution paths.
